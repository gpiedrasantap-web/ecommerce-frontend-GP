\# Ecommerce Frontend GP



Frontend para app de ecommerce con React, TypeScript y Vite.



\## Instalación

1\. `npm install`

2\. `npm run dev` (corre en localhost:5173)



\## Notas

\- Llamadas API apuntan al backend en http://localhost:3000/api (ajusta si cambia el puerto).

\- Usa Axios para fetch de datos (e.g., productos, pedidos).
